# 💼 Projetos Profissionais

Projetos desenvolvidos e implantados em ambiente corporativo através da organização **URE-JALES-GLPI**.

### 🚀 Acesso Rápido

**Hub central de links e recursos corporativos.**

Plataforma desenvolvida para centralizar acessos utilizados pela empresa, com página pública, busca, categorização, temas claro/escuro e banners de alerta.

Possui também painel administrativo para gerenciamento de acessos, usuários, grupos, permissões e estatísticas, além de uma área exclusiva para a equipe de TI com atalhos, anotações e anexos.

**Stack:** Node.js • Express • JSON • Multer

---

### 🖥️ Asset Manager Status

Plugin avançado para **GLPI**, desenvolvido para gerenciamento do ciclo de manutenção e transferência de ativos entre a URE e as escolas.

Possui fluxo de manutenção preventiva e corretiva, transferência de equipamentos, bloqueio de ativos durante processos, geração de documentos PDF, painel técnico, cronômetros por etapa, diário de manutenção e dashboards.

Também conta com relatórios e exportações em **CSV, PDF e XLSX**.

**Stack:** PHP 8.x • GLPI 10–12 • MySQL

---

### 📦 Cadastro de Ativos

Plugin para GLPI desenvolvido para **padronização e centralização do cadastro de ativos**.

Permite registrar patrimônio, fabricante, modelo, número de série, tipo, status, entidade e observações através de uma interface integrada ao GLPI.

O sistema foi desenvolvido para reduzir inconsistências no inventário e facilitar auditorias e gestão do ciclo de vida dos equipamentos.

É também utilizado como base de dados por outros projetos do ecossistema.

**Stack:** PHP 8.x • GLPI 11.x

---

### 🗺️ Floorplan

Plugin visual para GLPI que permite cadastrar **plantas baixas da instituição e posicionar ativos fisicamente nos ambientes**.

Através dele é possível navegar por prédio, setor e sala, localizar rapidamente equipamentos e consultar sua posição diretamente pelo inventário.

A solução transforma o inventário tradicional em uma representação visual da infraestrutura física.

**Stack:** PHP 8.x • GLPI 11.x

---

### 📁 Sistema de Protocolo

Sistema web independente desenvolvido para gerenciamento do **protocolo de pastas da URE**.

O fluxo contempla entrada de documentos, geração automática de protocolo, emissão de Termo de Recebimento, upload do documento assinado, retirada e geração do Termo de Entrega.

Possui dashboard, controle de pendências, histórico completo, perfis de acesso, logs e código de verificação nos documentos gerados.

**Stack:** PHP 8 • MySQL 8 • Apache

---

### ☎️ Ramal

Sistema leve de **lista telefônica corporativa**, desenvolvido sem banco de dados.

Permite consulta rápida de ramais e gerenciamento administrativo de registros.

Foi projetado para ser simples de instalar e manter, utilizando apenas PHP e armazenamento em JSON.

**Stack:** PHP • JSON • Apache

---

### 💬 WhatsApp Simples

Integração do **WhatsApp diretamente ao GLPI**, permitindo centralizar a comunicação sem depender de uma aplicação externa.

O sistema possui comunicação em tempo real, conversas individuais e em grupo, envio de imagens, documentos, vídeos e áudios, histórico, busca e notificações.

A solução utiliza Node.js para comunicação com o WhatsApp e integra a interface diretamente ao ambiente do GLPI.

**Stack:** PHP • GLPI 11.x • Node.js • Baileys • WebSocket
